# ATM-design
# GOAL:
To withdraw money from an ATM.

# STEPS WHEN THINGS GO RIGHT:
1. insert card
2. read and verify card
3. request pin
4. validate pin
5. select "withdraw"
6. enter amount
7. check balance
8. check ATM cash supply
9. dispense cash
10. update account balance
11. return card

# STEPS FOR FAILURE:
1. card can't be read
2. pin incorrect
3. amount > balance
4. ATM out of cash
5. Transaction can't complete
